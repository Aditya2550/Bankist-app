## **Bankist — A Simple Banking Application**
This is a simple bank application replica. It demonstrates core banking features

Functionalities such as: <br>
• User Login System
   Login using a predefined username and PIN.

• Account Overview <br>
   View your current balance, total deposits, total withdrawals, and interest earned.

• Interest Calculation <br>
   Interest is automatically calculated and added based on recent deposits.

• Transaction History with Dates <br>
   Every deposit and withdrawal is displayed along with its timestamp, formatted in a clean and readable way.

• Money Transfer <br>
   Transfer money to another user account (if valid and sufficient balance).

• Request Loan <br>
   Request a loan based on certain eligibility conditions.

• Close Account <br>
   Delete an account permanently using the username and PIN.
